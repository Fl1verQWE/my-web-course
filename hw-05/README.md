# 🍳 Cookly — Recipe Collection

Cookly is a web service for saving and organizing your favorite recipes. Users can create their own digital cookbook, discover new dishes, and plan their meals.

## 📌 About the Project

This project was created as part of a web development course.

Currently, Cookly is a landing page built using HTML. In the future, CSS, JavaScript, and interactive features will be added.

## 🚀 Features

- Save your favorite recipes
- Search for recipes by category
- Create your own recipes
- Make ingredient shopping lists
- Rate your favorite dishes
- Choose a subscription plan

## 🛠 Technologies

- HTML5
- CSS3 (planned)
- JavaScript (planned)

## 📂 Project Structure

```text
Cookly/
├── index.html
└── README.md
```

## 💻 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 📅 Future Plans

- Add CSS styling
- Implement form functionality using JavaScript
- Create a recipe catalog
- Allow users to save their own recipes
- Make the website responsive

## 📄 Project Status

🚧 This project is currently under development.
